# Cats Bot 0.4.1 — Standard Preview

A Windows fix for notes on the wallpaper: moving a note off the wallpaper no longer
leaves a white rectangle behind. A patch release with no data or contract changes.

## What changed

- **No more white blocks on the wallpaper (Windows).** A note on the wallpaper
  layer that was moved to the desktop layer, opened, hidden, deleted, or still
  there when Cats Bot quit left a white rectangle where it had been. Explorer
  does not draw the wallpaper again there by itself, so Cats Bot now asks it to
  whenever a note leaves the wallpaper. Nothing is asked of Explorer if you never
  use the wallpaper layer. A white block left by an earlier version clears the
  next time a note leaves the wallpaper.
- **A hidden note stays hidden when its layer changes.** Choosing the desktop,
  wallpaper or another layer for a hidden note in a bot's settings no longer
  shows it.

## Compatibility, upgrade and recovery

- **A patch.** No file format, registry field, CLI command or host contract
  changes; bot data, ids and the Boss Cat assignment are kept as they are.
- **From 0.3.x or 0.2.x.** Follow the 0.4.0 release notes; 0.4.1 changes nothing
  there.
- **Rollback.** 0.4.0 reads the same data. Its wallpaper notes leave white blocks
  again, which clear when Explorer next redraws the wallpaper (for example after
  changing the wallpaper or restarting Explorer).
