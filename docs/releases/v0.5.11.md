## Compatibility, backup and recovery

No mandatory data migration or public Bot contract change is introduced. The
experimental SQLite implementation was withdrawn before any Bot release and
remains absent. Runtime npm and Platform/Desktop releases are separate targets.

Before installation, stop Cats Bot and processes using its roots. Back up
`~/.catsbot` or configured CATS_BOT_HOME/overrides, Electron preferences and
`.cats-attachments/` in each Bot working directory. On installation or startup
failure, preserve those roots and reinstall 0.5.11 or return to 0.5.10 with
processes stopped. Restore backups only while writers are stopped; rollback
does not recreate data explicitly purged by the owner.

## Standard distribution and trust

Windows x64/arm64 receive NSIS installers and portable EXEs; macOS receives a
universal x64/arm64 DMG and updater ZIP; Linux amd64/arm64 receive DEBs.
Standard expected trust is macOS **signed + notarized**, Windows **unsigned:
no certificate**, Linux **n/a**. Native checks and per-platform receipts establish
actual trust. Same-team signed macOS, Windows NSIS and Linux DEB retain their
update paths; portable and unsigned macOS installations require manual replacement.

Publication results: the `v0.5.11` GitHub Standard Preview, platform/source
receipts, checksums, provenance and Actions run.
