# Cats Bot 0.5.7 — Standard Preview

This compatible 0.5 patch gives the tray a platform-native Cat, keeps the size a
maximized note restores to, and redraws the note's layer button. It introduces
no data migration or new provider.

## Changes

- **A tray Cat that fits the menu bar and the taskbar.** On macOS the hub's tray
  icon is a template image: the default Cat's silhouette with the eyes, nose and
  mouth knocked out, drawn by the menu bar in its own colour and sized like Cats
  Desktop's. Windows and Linux show the same silhouette in white on an amber tile,
  legible on light and dark taskbars. The window and installer icons are
  unchanged. (cats-bot#132)
- **A maximized note keeps its own size.** A double-click on a note's header
  maximizes it on Windows, macOS and Linux, and the shell saved the maximized
  bounds, so a note maximized when Cats Bot quit reopened screen-sized but not
  maximized. A maximized or full-screen note now keeps the position and size it
  restores to, including through the frames of macOS's zoom animation. A note
  saved screen-sized by an earlier version keeps that size until it is resized.
  On Windows, attaching to the desktop or wallpaper layer is as in 0.5.6: a note
  maximized while it is lifted, or while it is an ordinary window waiting for
  Explorer's host, is attached at the screen's size, and a header double-click
  on an attached desktop note can maximize it across Explorer's host, which may
  span every display. Restore the note before it returns to its layer.
  (cats-bot#133, cats-bot#135)
- **A layer button that no longer looks like maximize.** The note header's layer
  button showed `▢` for an ordinary window and emoji for the other layers. It now
  draws three plates stacked back to front (always on top, desktop, wallpaper):
  the note's layer is filled, and an ordinary window shows an outlined top plate
  over two faint ones. The button has an accessible label. (cats-bot#133)

## Compatibility, backup and recovery

Profile schema 2, registry schema 1, conversations, hub/shell state (including
`shell-state.json`, whose fields are unchanged), session attachments, lock
identity, public API, CLI and configuration retain their formats. Existing 0.5
profiles need no conversion or reset. Before installation, stop Cats Bot and
processes using its data roots, and back up `~/.catsbot` or configured
`CATS_BOT_HOME`/overrides, Electron preferences such as `%APPDATA%\Cats Bot`, and
existing Runtime configuration backups.

If installation or startup fails, preserve those directories and reinstall 0.5.7
or return to 0.5.6 without data conversion. Returning restores the previous tray
icons and layer button, and a note maximized at quit again reopens screen-sized.
Restore backups only with all processes using those roots stopped.

## Standard distribution and trust

Windows x64/arm64 receive NSIS installers and portable EXEs; macOS receives a
universal x64/arm64 DMG and updater ZIP; Linux amd64/arm64 receive DEBs. Expected
Standard trust is macOS **signed + notarized**, Windows **unsigned: no
certificate**, Linux **n/a**. Native checks and per-platform receipts establish
actual trust. NSIS, same-team signed macOS and Linux DEB retain their update paths;
portable and unsigned macOS installations require manual replacement.

Publication results: the `v0.5.7` GitHub Standard Preview, platform receipts and
Actions run. Verification checks immutable status, tag source, complete public
assets and hashes, updater metadata and release attestation.
