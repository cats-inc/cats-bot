# Cats Bot 0.5.13 — Standard Preview

This compatible 0.5 patch wakes a cat whose unused replacement session was stopped by a restart or by rest
hours, and polishes the note window: its own tooltips, a paw cursor, the cat's face in the title bar, who
speaks on which side, a time in every bubble and a scroll-to-latest button. Bot keeps profile schema 2,
version-1 conversations and JSONL journals; the one new presentation field is optional.

## Changes and exact inputs

- **Source selection:** cats-runtime@512c074713cbe563124f21c4ed9218e0b408c33f; main@512c074713cbe563124f21c4ed9218e0b408c33f.
- **A cat no longer stays silent after an unused replacement (#183 and its review fixes, SPEC-001 FR-27).** A
  replacement session waits for its first turn before the core trusts it. When the app quit, or rest hours
  closed the session, before that turn, every later start refused it, and only an owner message could get
  past. A cat waiting for the owner therefore never woke, wrote nothing to its log, and sent no messages of
  its own initiative.
  - The background check now replaces such a session when its stop was not its own: an earlier run made it,
    this core closed it (rest hours or the note's idle close), or Runtime exited. A session that stopped by
    itself stays refused, so no new provider worker opens on every check.
  - If that background try fails in any way, the session's state is restored, so the owner's next message
    can still rebuild it. A try that may have left a worker (a timeout) is made once per session per run; a
    try Runtime refused outright (not answering yet, no capacity, a 4xx other than 408) left none, so the
    check tries again after its usual back-off.
  - When an owner's turn meets such a refusal, the next turn may try again too. Uncertain failures stay
    refused.
  - A refused session writes one log line per session.
  - Replacing a session that never ran a turn no longer adds the "new session" line, since no conversation
    was lost.
  - Rarer cases remain refused until a turn completes or the session is reset: an unused replacement whose
    Runtime record is missing or ended, a turn that ran without a provider session ID, and a first session
    this run made that stopped by itself before any turn and whose replacement then timed out (as in 0.5.12).
    Changing the cat's model or instructions creates a new session.
  - A refusal that never clears (no capacity, or a model Runtime rejects) is retried once per wake back-off,
    about every 5 minutes, with two log lines each time; Runtime starts no worker for it.
- **Tooltips and cursors (#183, SPEC-003 FR-11).** The note opens without taking focus, and macOS shows native
  tooltips only for the active app, so the note's tooltips never appeared. The note now draws its own, after
  300 ms or at once when moving between buttons, and on keyboard focus. Buttons in the note, Settings and the
  floating cat use a paw cursor (an inline image, falling back to the hand); the (i) uses the arrow.
- **Faces and sides (#183, SPEC-003 FR-16, SPEC-009 FR-10, SPEC-012 FR-6).** The title bar starts with the
  cat's small face, ringed in gold for the Boss Cat, which replaces the "Boss Cat" text. A direct note shows
  no face over the cat's replies. A message from another cat shows that cat's face and name. In a contact
  note the Boss Cat's messages are on the right and the cat it looks after is on the left with its face, and
  the title bar shows that cat's face.
- **Times (#183, SPEC-003 FR-13).** Every bubble ends with its time, inside the bubble, with the full date in
  its tooltip. A reply shows when it finished (`presentationEndedAt`); a reply still being written shows no
  time. A line written while a reply ran no longer starts a day again. A message the cat sends on its own is
  labeled 自主訊息 ("On its own initiative"), matching the 自主 switch on the cat's menu. Copy copies the
  message alone.
- **Send button and scrolling (#183, SPEC-003 FR-15, FR-17).** The paper plane shows only in a direct message
  that reaches Telegram (enabled, token stored, owner chat bound); otherwise the up arrow. A floating button
  scrolls to the latest message when the transcript is not at the end, above any composer notice.
- **Settings.** Settings › Conversations lists "Show verbose messages" before "Show live progress details", as
  Cats Desktop does. Session errors such as "Automatic session replacement stopped…" stay visible with verbose
  messages off, because they explain why a cat is not answering (SPEC-003 FR-14).

## Compatibility, backup and recovery

No mandatory data migration or public Bot contract change is introduced. A sealed reply's presentation gains
the optional `presentationEndedAt`; a reply without it shows its start time, and 0.5.12 ignores the field.
The note's `window:state` adds `peers`, read only by this version's own note window. Conversations, journals,
transcripts and profiles keep their formats.

After upgrading, a cat whose unused replacement session was refused before may be given a new session by the
next background check, without the "new session" line. Replies show the time they finished instead of when
their turn started.

Before installation, stop Cats Bot and processes using its roots. Back up `~/.catsbot` or configured
CATS_BOT_HOME/overrides, Electron preferences and `.cats-attachments/` in each Bot working directory. On
installation or startup failure, preserve those roots and reinstall 0.5.13 or return to 0.5.12 with
processes stopped; 0.5.12 reads the same data and ignores `presentationEndedAt`.
Restore backups only while writers are stopped; rollback does not recreate data explicitly purged by the
owner.

## Standard distribution and trust

Windows x64/arm64 receive NSIS installers and portable EXEs; macOS receives a universal x64/arm64 DMG and
updater ZIP; Linux amd64/arm64 receive DEBs. Standard expected trust is macOS **signed + notarized**,
Windows **unsigned: no certificate**, Linux **n/a**. Native checks and per-platform receipts establish
actual trust. Same-team signed macOS, Windows NSIS and Linux DEB retain their update paths; portable and
unsigned macOS installations require manual replacement.

Publication results: the `v0.5.13` GitHub Standard Preview, platform/source receipts, checksums,
provenance and Actions run.
