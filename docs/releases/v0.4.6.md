# Cats Bot 0.4.6 — Standard Preview

This compatible 0.4 patch recognizes existing Claude browser/subscription login
on Windows and adds bounded local host diagnostics for installed builds.

## Changes

- **Recognize Claude subscription login on Windows** (#97). Provider setup asks
  the installed CLI for `auth status --json` through a hidden process with a
  10-second timeout. A successful boolean `loggedIn` result marks the provider
  ready and clears unnecessary login guidance. Existing API-key support remains.
  The helper does not read credential files or return the CLI's authentication
  output. macOS/Linux helper bytes and installation-readiness behavior are unchanged.
- **Bound local diagnostics** (#96). The hub records startup, display/window and
  renderer/core lifecycle metadata locally. Host/core logs rotate at 256 KiB with
  three backups; core stderr retains a bounded previous snapshot and periodically
  bounds its current file. `CATS_BOT_LOG_LEVEL=debug` enables detailed window
  diagnostics. No crash dumps or diagnostic uploads are enabled. See the
  [diagnostic log guide](../setup-guide.md#diagnostic-logs) for locations and limits.
- Closing setup or quitting during read-only provider detection continues to
  cancel the helper process tree without creating a bot, as introduced in 0.4.5.

## Downloads, signing and updates

- Windows x64/ARM64: `Cats-Bot-0.4.6-setup-<arch>.exe` and
  `Cats-Bot-0.4.6-portable-<arch>.exe`; updater `latest.yml`.
- macOS Universal (Intel x64 + Apple Silicon ARM64):
  `Cats-Bot-0.4.6-universal.dmg`, updater ZIP and `latest-mac.yml`.
- Debian/Ubuntu amd64/ARM64: `Cats-Bot-0.4.6-<arch>.deb`, with architecture-specific
  updater metadata.
- Per-platform receipts, `SHA256SUMS`, `Cats-Bot-v0.4.6-source.zip` and
  `Cats-Bot-v0.4.6-sources.json` accompany the installers.

Standard-profile expected trust: macOS **signed and notarized**, Windows
**unsigned: no certificate** (including the desktop-control helper), Linux
**n/a**. Receipts record actual trust and configured signature/notarization gates
enforce it. No unsigned override is selected.

Existing 0.4.x Windows NSIS and signed macOS installs using the same Developer ID
team retain their Check for Updates path. Linux uses the package manager.
Portable and unsigned Mac installations use manual replacement. There is no
automatic background installation. GitHub immutable releases and the active
`v*` tag protection remain enabled; publication attaches all assets before locking.

## Compatibility, backup and recovery

- Profile schema 2, hub/shell state, conversations, permission contracts and
  CLI/HTTP APIs remain unchanged. No data migration or session reset is introduced.
  Diagnostic log retention bounds ordinary logs, not execution state.
- Before changing installations, stop Cats Bot and retain a copy of its data
  root (`~/.catsbot`, or the configured `CATS_BOT_HOME`) and Electron preferences.
  If installation fails, keep those directories intact and reinstall 0.4.6.
- The 0.4.5 installer reads the same data without conversion. Rolling back
  restores its Windows Claude login misdetection and previous diagnostic behavior;
  preserve local installer/profile backups for recovery.
