# Cats Bot 0.4.4 — Standard Preview

This compatible 0.4 patch refreshes Bot's shared Runtime model catalog, fixes the
macOS tray update alert's position and keeps the Boss Cat note header concise.

## Changes

- **Refreshed models** (#91). Codex adds **GPT-6.1 Terra**, with Low, Medium,
  High, Extra high, Max and Ultra effort, default **Low**, context **500000**.
  Bot keeps only **Codex, Claude, Antigravity, Grok and Muse**, with 8/12/5/4/3
  entries respectively. Existing models, their controls/defaults and custom
  model input remain available. No provider or model table is added to Bot.
- **macOS tray update alert** (#90). The update alert opens at macOS's native
  position after activating the app through a short-lived transparent window.
  Windows and Linux behavior is unchanged.
- **Boss Cat note header** (#92). The holder's note header says only **Boss Cat**.
  Whether that provider gives the role tools is explained in Settings → Bots.
  Non-holder note headers and tool permissions are unchanged.

## Downloads, signing and updates

- Windows x64/ARM64: `Cats-Bot-0.4.4-setup-<arch>.exe` and
  `Cats-Bot-0.4.4-portable-<arch>.exe`; updater `latest.yml`.
- macOS Universal (Intel x64 + Apple Silicon ARM64):
  `Cats-Bot-0.4.4-universal.dmg`, updater ZIP and `latest-mac.yml`.
- Debian/Ubuntu amd64/ARM64: `Cats-Bot-0.4.4-<arch>.deb`, with architecture-specific
  updater metadata.
- Receipts, `SHA256SUMS`, `Cats-Bot-v0.4.4-source.zip` and
  `Cats-Bot-v0.4.4-sources.json` accompany the installers.

Standard-profile expected trust: macOS **signed and notarized**, Windows
**unsigned: no certificate** (including the desktop-control helper), Linux
**n/a**. Actual trust is recorded in the build receipts and enforced by the
signature/notarization gates. Standard-profile 0.4.3 Windows NSIS and signed
macOS installs using the same Developer ID team retain their update paths;
Linux uses the package manager. Portable and unsigned Mac installations use
manual replacement. There is no automatic background installation.

## Compatibility, rollback and exact inputs

- Bot remains in the compatible 0.4 line. Profile schema 2, hub/shell state,
  conversation records, permission contracts and CLI/HTTP APIs are unchanged.
  No data migration or session reset is introduced. Existing resolved sessions
  keep their bindings; future selections use the current catalog.
- Returning to 0.4.3 needs no format conversion. Its factory omits Terra, so
  choose another offered model or a supported custom raw ID when necessary.
  It also restores the older note-header text and macOS alert positioning.

  `vendor/cats-runtime-0.6.2-c6e575b6.tgz`, SHA-256

  Its 1,473-file archive differs from the 0.4.3 Runtime artifact only in the
  authored/generated catalogs. Catalog sourceDigest:
  `b9f8c46b2b9add026804082b219a0d3350ab17f264b2c481beb00dc3cfacff64`.

  `363e784f2d0571522006797b01772be55384ecec4ae0bccb254eabd7b6783501`.
