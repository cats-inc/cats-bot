# Cats Bot 0.4.5 — Standard Preview

This compatible 0.4 patch lets first-run setup close while provider detection is
running. It also starts GitHub-enforced immutable publication after the previous
hosted releases and tags were removed at the owner's request.

## Changes

- **Close setup during provider checks** (#94). Closing first-run setup cancels
  its read-only provider check and exits without creating a bot. The New bot
  window also closes during checks, and a late result cannot create a bot after
  its window has closed. Explicit installations and the short bot-creation step
  still finish before setup closes.
- **Quit cancels detection.** Quit cancels read-only checks, including startup
  probes, and waits for their helper/CLI process trees to stop. Startup does not
  begin another provider probe or open windows after shutdown starts.
- **Release protection.** GitHub immutable releases lock published assets and
  their source tag. The active `Protect release tags` ruleset restricts updates
  and deletion of `v*` tags with no bypass actors, matching Cats Desktop. The
  publication workflow can create the new tag. Previous GitHub release assets
  and tags are no longer hosted; version 0.4.5 does not reuse an old version.

## Downloads, signing and updates

- Windows x64/ARM64: `Cats-Bot-0.4.5-setup-<arch>.exe` and
  `Cats-Bot-0.4.5-portable-<arch>.exe`; updater `latest.yml`.
- macOS Universal (Intel x64 + Apple Silicon ARM64):
  `Cats-Bot-0.4.5-universal.dmg`, updater ZIP and `latest-mac.yml`.
- Debian/Ubuntu amd64/ARM64: `Cats-Bot-0.4.5-<arch>.deb`, with architecture-specific
  updater metadata.
- Per-platform receipts, `SHA256SUMS`, `Cats-Bot-v0.4.5-source.zip` and
  `Cats-Bot-v0.4.5-sources.json` accompany the installers.

Standard-profile expected trust: macOS **signed and notarized**, Windows
**unsigned: no certificate** (including the desktop-control helper), Linux
**n/a**. Actual trust is recorded in the receipts and enforced by the configured
signature/notarization gates. No unsigned override is selected.

Existing 0.4.x Windows NSIS and signed macOS installs using the same Developer ID
team retain their Check for Updates path. Linux uses the package manager.
Portable and unsigned Mac installations use manual replacement. There is no
automatic background installation.

## Compatibility, backup and recovery

- Profile schema 2, hub/shell state, conversations, permission contracts and
  CLI/HTTP APIs remain unchanged. This patch introduces no data migration or
  session reset; existing bot data and assignments are preserved.
- Before changing installations, stop Cats Bot and retain a copy of its data
  root (`~/.catsbot`, or the configured `CATS_BOT_HOME`) and Electron preferences.
  If installation fails, keep those directories intact and reinstall 0.4.5.
- A retained 0.4.4 installer reads the same data without conversion, but restores
  the provider-check close restriction. Older GitHub downloads and tags were
  removed, so rollback requires an already retained installer or source checkout.
  A local installer/profile backup is not a promise that deleted hosted files
  can be downloaded again.
