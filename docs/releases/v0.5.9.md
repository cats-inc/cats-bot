# Cats Bot 0.5.9 — Standard Preview

This compatible 0.5 update recovers a warm session stopped before its first turn,
adds the implemented Boss Cat status-board slice and utility-window controls,
and repairs macOS dictation. Existing conversations and provider configuration
retain their formats; no mandatory data conversion is introduced.

## Changes

- **Recover a genuinely unstarted worker.** A closed Runtime-owned CLI session
  with no native ID can continue in one replacement with a transcript handoff
  and visible notice. Zero completed messages alone is insufficient: Runtime
  history/run evidence and Bot's durable attempted-run journal must also be
  absent. Authentication, policy and failed-bootstrap mappings remain intact;
  the replacement fence survives restart until a successful turn. (cats-bot#160)
- **Respect archived native history.** Runtime classifies Codex's archived
  thread/resume rejection as provider_session_unavailable. Bot uses its existing
  bounded handoff recovery without unarchiving the native thread.
  (cats-runtime#218)
- **Boss Cat status board and contact notes.** The hub exposes the implemented
  SPEC-012 phase-one board and scoped contact notes. This does not implement
  the proposed SQLite state store or layered-memory consolidation.
  (cats-bot#157)
- **Settings and utility windows.** Grouped settings rows, independently saved
  setup/settings placement and explicit data-reset controls retain Runtime
  storage by default, with a separately chosen purge and interrupted-reset
  recovery. (cats-bot#151, cats-bot#156)
- **macOS dictation.** Recognition callbacks no longer block the run loop;
  a missing microphone fails explicitly. (cats-bot#159)

## Compatibility, backup and recovery

No mandatory migration, provider change or public contract break is introduced.
Existing optional recovery, window and settings fields retain their normalizers
and atomic writers. Data reset is explicit user action, not an install step;
it preserves Runtime storage unless the owner separately selects its purge.

Before installation, stop Cats Bot and all processes using its roots. Back up
`~/.catsbot` or configured CATS_BOT_HOME/overrides, Electron preferences such as
`%APPDATA%\Cats Bot`, and `.cats-attachments/` in each Bot working directory.
On installation/startup failure, preserve those directories and reinstall 0.5.9
or return to 0.5.8. Restore backups only while their writers are stopped.
Returning loses these fixes and controls; neither installation nor rollback
recreates data explicitly purged through Settings.

## Standard distribution and trust

Windows x64/arm64 receive NSIS installers and portable EXEs; macOS receives a
universal x64/arm64 DMG and updater ZIP; Linux amd64/arm64 receive DEBs.
Standard expected trust is macOS **signed + notarized**, Windows **unsigned:
no certificate**, Linux **n/a**. Native checks and per-platform receipts establish
actual trust. Same-team signed macOS, Windows NSIS and Linux DEB retain their
update paths; portable and unsigned macOS installations require manual replacement.

Publication results: the `v0.5.9` GitHub Standard Preview, platform/source receipts,
checksums, provenance and Actions run.
