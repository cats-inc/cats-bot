# Cats Bot 0.5.12 — Standard Preview

This compatible 0.5 patch reworks how a note shows failures, steps, system lines and time, aligns its
controls with Cats Desktop's, and adds two display switches. Bot keeps profile schema 2, version-1
conversations and JSONL journals; the two new profile fields are optional.

## Changes and exact inputs

- **Source selection:** cats-runtime@512c074713cbe563124f21c4ed9218e0b408c33f; main@512c074713cbe563124f21c4ed9218e0b408c33f.
- **Composer failures (#178, #179, #180, ADR-024).** A failed dictation, screenshot, oversized
  attachment, send or retry is one notice at the top of the composer instead of a transcript line pinned
  under every later reply. A new failure replaces it; it stays until the owner closes it or the action
  works again, and it never moves the draft or the buttons. A permission notice keeps "Open System
  Settings" (ADR-020).
- **Composer and header controls (#179, #180).** Attach is a paperclip and the screenshot a dragged-out
  region (Traditional Chinese label 擷取畫面). Send is Cats Desktop's round up arrow, and a paper plane in
  the direct message. The header's settings, layer and hide buttons are equal 24 px squares, every
  icon-only button has a tooltip, and the header status stays on one line. An (i) after the title shows,
  on hover or focus, the bot's provider, model and reasoning effort as the model catalog names them; the
  Boss Cat's role now follows the bot's name. The note's gear opens Settings › Conversations.
- **Live progress details (#181, SPEC-003 FR-12).** "Show input and result" at the top of every
  transcript is replaced by Cats Desktop's "Show live progress details", one saved switch per bot in
  Settings › Conversations, off by default. On, a reply still being written shows its tool steps as they
  come and a finished reply folds them behind its own "3 steps ▸" link; a finished reply with nothing but
  steps keeps them open. The core now announces execution target changes too, so the header's (i) follows
  a model change.
- **Dates and verbose messages (SPEC-003 FR-13, FR-14).** A bubble shows its time to the minute with the
  full date and time in its tooltip, and each new local day starts with a divider (Today, Yesterday, then

## Compatibility, backup and recovery

No mandatory data migration or public Bot contract change is introduced. The profile gains two optional
booleans, `showProgressDetails` and `showVerboseMessages`; an absent or invalid value reads as off, neither
is a session setting, and 0.5.11 ignores both. After upgrading, a reply's tool steps are still folded by
default, as they were in 0.5.11, but they open from the saved per-bot switch and each reply's link instead
of the transcript's unsaved "Show input and result" button. Replies recorded without a presentation, such as
unprompted heartbeat turns and older transcripts, keep showing their tool cards. The system lines about
sessions and schedules are now hidden until "Show verbose messages" is turned on, times show without
seconds, and day dividers appear. Conversations, journals and transcripts are unchanged; the failure lines a
note used to add by itself were never stored.

Before installation, stop Cats Bot and processes using its roots. Back up `~/.catsbot` or configured
CATS_BOT_HOME/overrides, Electron preferences and `.cats-attachments/` in each Bot working directory. On
installation or startup failure, preserve those roots and reinstall 0.5.12 or return to 0.5.11 with
processes stopped; 0.5.11 reads the same data and ignores the two switches, and drops them from the profile
the next time it saves it.
Restore backups only while writers are stopped; rollback does not recreate data explicitly purged by the
owner.

## Standard distribution and trust

Windows x64/arm64 receive NSIS installers and portable EXEs; macOS receives a universal x64/arm64 DMG and
updater ZIP; Linux amd64/arm64 receive DEBs. Standard expected trust is macOS **signed + notarized**,
Windows **unsigned: no certificate**, Linux **n/a**. Native checks and per-platform receipts establish
actual trust. Same-team signed macOS, Windows NSIS and Linux DEB retain their update paths; portable and
unsigned macOS installations require manual replacement.

Publication results: the `v0.5.12` GitHub Standard Preview, platform/source receipts, checksums,
provenance and Actions run.
