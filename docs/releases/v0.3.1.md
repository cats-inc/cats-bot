# Cats Bot 0.3.1 — Standard Preview

Fixes the first launch of 0.3.0. The setup page's provider check showed
"ReferenceError: Cannot access 'manager' before initialization", so no first
bot could be created.

## First run

- The provider check on the setup page reports each component again, and
  **Create and start** creates the first bot, starts it and opens its direct
  message.
- 0.3.0 hubs that already had bots were not affected, and neither was a first
  launch with `--provider`.

  - `SHA256SUMS`
  - `Cats-Bot-v0.3.1-source.zip`
  - `Cats-Bot-v0.3.1-sources.json`
- **Updating:**
  - A 0.3.0 install still on the setup page has no tray yet, so it cannot
    check for updates. Quit it, then install 0.3.1 over it.
  - Otherwise, Windows NSIS and signed macOS builds keep **Check for Updates**,
    which stops every bot the hub runs before installing.
  - Linux DEBs use the package manager.
  - Portable builds are replaced by hand.

## Compatibility, upgrade and recovery

- **A compatible 0.3 patch.** Data formats, the CLI, the hub files and the
  coordinator are unchanged. There is no migration.
- **From 0.2.x.** There is still no upgrade. Follow the steps in the 0.3.0
  release notes: turn off Start at login in 0.2.x, uninstall it without
  updating, then install 0.3.1.
- **Rollback.** Going back to 0.3.0 needs no conversion, but its first launch
  fails again.
