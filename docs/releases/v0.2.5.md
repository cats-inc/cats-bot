# Cats Bot 0.2.5 — Standard Preview

Fixes a conversation window reappearing after it was closed during startup,
which could make the direct message require a second close after restarting Bots.

## Conversation windows

- Closing a conversation takes precedence over a delayed startup restore or
  page load. A stale restore list cannot reopen an already hidden window.
- Overlapping open requests wait for the existing page to load, and delayed
  desktop focus events leave hidden conversations hidden.
- Opening a conversation explicitly from the tray or avatar still works.

## Compatibility, upgrade and recovery

This is a compatible patch within Bots 0.2. Profile schema 2, shell-state schema 1,
conversation IDs, transcripts, CLI/config contracts and Runtime pins are unchanged.
No data migration or transcript rewrite is required.

Before upgrading, quit the Bots and back up `~/.cats/bots` (or `CATS_BOTS_HOME`).
Unknown/corrupt profiles preserve the original data. An uncertain installer
handoff keeps its update gate until the replacement starts or the owner confirms
the installer finished. To roll back, stop all Bots, reinstall the older app and
restore the pre-upgrade data backup. Pre-0.2 readers still reject profile schema 2.
