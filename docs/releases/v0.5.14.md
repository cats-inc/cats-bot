# Cats Bot 0.5.14 — Standard Preview

This compatible 0.5 patch says plainly when a new Boss Cat gets its tools, gives every cat's face the look of
a portrait with the bot's model on hover, and keeps the system pointing hand on macOS. Bot keeps profile
schema 2, version-1 conversations and JSONL journals.

## Compatibility, backup and recovery

No data migration or public Bot contract change is introduced. Cats Bot Settings' internal bot listing now
carries the holder's tools as a state instead of a yes or no; only this version's own Settings page reads it.
Conversations, journals, transcripts and profiles keep their formats.

Before installation, stop Cats Bot and processes using its roots. Back up `~/.catsbot` or configured
CATS_BOT_HOME/overrides, Electron preferences and `.cats-attachments/` in each Bot working directory. On
installation or startup failure, preserve those roots and reinstall 0.5.14 or return to 0.5.13 with
processes stopped; 0.5.13 reads the same data. Restore backups only while writers are stopped; rollback does
not recreate data explicitly purged by the owner.

## Standard distribution and trust

Windows x64/arm64 receive NSIS installers and portable EXEs; macOS receives a universal x64/arm64 DMG and
updater ZIP; Linux amd64/arm64 receive DEBs. Standard expected trust is macOS **signed + notarized**,
Windows **unsigned: no certificate**, Linux **n/a**. Native checks and per-platform receipts establish
actual trust. Same-team signed macOS, Windows NSIS and Linux DEB retain their update paths; portable and
unsigned macOS installations require manual replacement.

Publication results: the `v0.5.14` GitHub Standard Preview, platform/source receipts, checksums,
provenance and Actions run.
