# Cats Bot 0.2.4 — Standard Preview

Aligns the Bot's desktop experience with Cats Desktop: native update dialogs,
language selection, restored windows, provider-first setup and shared model catalogs.

## Desktop behavior

- Tray **Check for Updates…** opens a native result/action dialog. **Update and
  Restart** explicitly starts download and installation; Settings retains its
  separate download and restart actions.
- Choose **System**, **English** or **繁體中文** during setup or in Settings.
  Conversations, settings, menus and native dialogs update without restarting.
- Restart restores the avatar's position/visibility and each conversation's
  position, size, visibility and layer, including an intentionally all-hidden state.
- Onboarding selects a provider first, then checks and offers installation of
  only that provider's requirements. Codex checks Node/npm before Codex; native
  Claude uses its native installer. Install actions require their buttons, and
  provider authentication remains a separate step.
- Model and effort choices come from Runtime's catalogs, including per-model
  controls and local overrides, without synthetic default/custom entries. The
  provider picker offers **Codex, Claude, Antigravity, Grok, Muse**, in that order.
  Previously saved providers outside that list remain executable and are kept
  when saving unrelated settings.
- The floating avatar no longer shows hover tooltips.
- Product labels use **Conversation** and **Direct message**. Existing IDs,
  transcripts and owner-assigned titles are preserved.

Expected Standard trust with the configured shared credentials: macOS
**signed + notarized**, Windows **unsigned: no certificate** (including its
desktop-control helper), Linux **n/a**. Actual trust is recorded in the three
platform build receipts. Missing macOS credentials can produce unsigned output;
that output cannot self-update an existing signed macOS installation.

The release also carries updater metadata, blockmaps, `SHA256SUMS`,
`Cats-Bot-v0.2.4-source.zip` and its source manifest. The source bundle includes
the Bot, its exact Runtime source and the vendored provider setup helpers.

When output trust matches this expectation, installed 0.2.3 Standard Previews
retain the same update eligibility: Windows NSIS and signed macOS update through
**Check for Updates**, Linux DEBs use the package manager, and portable builds
open the release page for manual replacement. Quit other Bots sharing the
installation first; the updating Bot stops its Runtime before replacement.
Unsigned macOS installations require a manual signed installation before
self-updates become available.

## Compatibility, upgrade and recovery

This is compatible within Bots 0.2. Profile schema 2 and shell-state schema 1
remain unchanged. Language preference and structured model/control selections
are optional fields; older profiles use defaults, and existing unset/custom
models are preserved on unrelated saves. No data migration or transcript rewrite
is required. Persisted conversation roles, IDs and CLI aliases remain compatible.

Before upgrading, quit the Bots and back up `~/.cats/bots` (or `CATS_BOTS_HOME`).
The 0.2.0 validated profile-backup and update-gate recovery procedures still apply:
unknown/corrupt profiles preserve the original data, and an uncertain installer
handoff retains its gate until the replacement starts or the owner confirms the
installer has finished. To roll back, stop all Bots and restore the pre-upgrade
data backup with the older application. Older versions do not implement the new
language/model-control preferences and may drop them when saving; pre-0.2 readers
still reject schema 2.
