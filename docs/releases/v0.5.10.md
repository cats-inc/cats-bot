# Cats Bot 0.5.10 — Standard Preview

This compatible 0.5 patch repairs update discovery and presents concise,
localized update failures. It retains the existing Bot profile, conversation
and journal formats; the experimental Bot database was withdrawn before release.

## Changes

- **Check for Updates.** A bare milestone tag such as `state-db-p1` no longer
  hides installable versions. Preview discovery orders plain version tags and
  requires matching per-platform metadata, safe versioned asset names, sizes,
  SHA-512 checksums and a compatible architecture's updater package. Missing or
  invalid metadata can fall back to another version; network, authorization and
  service failures remain errors. Native download, integrity, signature and
  installer handling are retained. (cats-bot#175)
- **Useful failure messages.** Tray and Settings show bounded English or
  Traditional Chinese summaries for native provider failures, including
  message-only Electron network errors. HTTP headers, raw URLs and generic
  token advice no longer occupy the native alert. Host-owned installation and
  recovery refusals retain their actionable guidance. (cats-bot#175)
- **Runtime refresh.** The selected Runtime adds preview-plugin installation
  and restart recovery, native Codex developer items for turn instructions,
  reference-based media jobs, and lazy loading of optional FFmpeg/FFprobe so
  missing media binaries do not block startup. These Runtime capabilities do
  not add a Bot media UI or new Bot provider. (cats-runtime#219 to #222)
- **Storage direction.** The unreleased SQLite state implementation was removed
  from Bot; Desktop pilots that direction first. This release keeps Bot's
  existing JSON/JSONL storage and does not perform a database cutover.
  (cats-bot#174)

## Compatibility, backup and recovery

No mandatory data migration or public Bot contract change is introduced.
Existing profile schema 2, version-1 conversations and JSONL journals remain in
use. The removed SQLite implementation was never a published Bot format.

Before installation, stop Cats Bot and processes using its roots. Back up
`~/.catsbot` or configured CATS_BOT_HOME/overrides, Electron preferences and
`.cats-attachments/` in each Bot working directory. On installation or startup
failure, preserve those roots and reinstall 0.5.10 or return to 0.5.9 with
processes stopped. Restore backups only while their writers are stopped.
Neither installation nor rollback recreates data explicitly purged by the owner.

## Standard distribution and trust

Windows x64/arm64 receive NSIS installers and portable EXEs; macOS receives a
universal x64/arm64 DMG and updater ZIP; Linux amd64/arm64 receive DEBs.
Standard expected trust is macOS **signed + notarized**, Windows **unsigned:
no certificate**, Linux **n/a**. Native checks and per-platform receipts establish
actual trust. Same-team signed macOS, Windows NSIS and Linux DEB retain their
update paths; portable and unsigned macOS installations require manual replacement.

Publication results: the `v0.5.10` GitHub Standard Preview, platform/source
receipts, checksums, provenance and Actions run.
